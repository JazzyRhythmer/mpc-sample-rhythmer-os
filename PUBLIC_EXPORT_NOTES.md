# Public export adjustments

This repository starts with new public history from the reviewed beta source exports. Native Move source trees are included alongside the main export. Generated archive manifests remain with their immutable ZIPs. The public compile_moves.py and compile_drumx.py additionally accept RHYTHMER_BUILD_ROOT for portable output placement; their default maintainer path and DSP/compiler behavior are unchanged. Repository READMEs, build guidance and the approved boot preview are added for publication. Original copyright and licenses are retained.
