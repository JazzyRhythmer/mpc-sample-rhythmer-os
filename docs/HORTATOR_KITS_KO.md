# Hortator / Rhythmer Kit 구성

원본 팩토리 사운드를 조합한 Rhythmer 패드 배열입니다. 사운드의 파라미터·엔벌로프를 새로 만들거나 수정하지 않습니다.

기존 Hortator 킷 6종을 유지하고 MD 중심 6종을 추가했습니다. 전체 Rhythmer Kit는 30종에서 36종으로 늘었습니다.

## 기존 Hortator 킷

- Hortator / TRX Classic
- Hortator / 808
- Hortator / 909
- Hortator / Plaits
- Hortator / FM
- Hortator / Industrial

Existing six layouts keep their Hortator-centered voices with complementary original Sophie percussion where needed. The six added MD layouts use Hortator on every pad.

## 추가한 MD 킷

추가 6종은 16개 패드 모두 Hortator 원본 사운드입니다. EFM의 두 번째 하이햇 자리에는 원본의 다른 HH 사운드를 배치하며, 새 오픈햇 패치를 합성하지 않습니다.
