# Install RHYTHMER OS 0.2.0

Use **RHYTHMER-OS-0.2.0-SD.zip** for this release. It contains the app, installed plug-ins, presets and kits. **UPDATE.zip is app-only** and does not install the two new engine folders or the complete catalogue.

Compatibility: **Akai MPC Sample AC50, stock firmware 1.3.0.12**. This is early beta software. Back up your SD card, projects, User Sounds/Kits and original samples first. It runs through the SD launcher; it is not an in-place rewrite of the stock firmware.

## Standard SD installation

1. Stop playback and allow project saving to finish. Power off the MPC Sample.
2. Back up the card to your computer. Download the full SD ZIP and its `.sha256` file; compare the checksum before extracting.
3. Extract it. Copy **autorun**, **Rhythmer** and **Samples** to the top level of the card. Do not place them inside another folder. Keep the release's plug-in folders and catalogue together. The **Documentation** folder is the offline manual and can also be kept on the computer.
4. Eject the card safely, insert it into the MPC Sample and power on. Follow the launcher. If an automatic update is not offered, use this manual full-package installation.
5. Check RHYTHMER OS 0.2.0, then open a plug-in track. Rhythmer Kit, Frodhes and Tenebrae should be available. Plug-ins belong in **Rhythmer/Plugins**.

If you already use **Boot Thingy**, keep its launcher and follow its app installation instructions rather than overwriting it with the standard autorun folder. The standard SD procedure above describes RHYTHMER running as the card's launcher.

## Start using it

Open **Documentation/index.html** on your computer for the full manual. **Documentation/quickstart.html** is Your first groove; essentials.html and structure.html explain controls and track/pattern selection. Korean pages are linked from the manual. The same guides are available from the device's USB web page and the project website.

A normal NEW project starts with Rhythmer Kit / K-WASUB / 909 on track 1. Saved projects keep their instruments. Project → NEW → EMPTY starts an empty kit. SAMPLE plays sounds; PATTERNS selects patterns. Back/cancel is SHIFT + encoder **push**, not turn.

## Return to the stock app

Use the application's exit-to-MPC option when available. For a card-level removal, power off, remove the card and move **autorun** off the card. Keep project and sample backups. With Boot Thingy, select the desired installed app using its own menu instead of removing its launcher.

## Release files

- **SD.zip:** full installation.
- **UPDATE.zip:** app-only autorun update; not the complete new-engine installation.
- **SOURCE.zip / MOVE-SOURCE.zip / SUPPORT-SOURCE.zip:** corresponding source companions, not files to install as an app.
