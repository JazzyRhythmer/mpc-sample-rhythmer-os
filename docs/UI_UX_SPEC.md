# Interface

Use existing sequence, sampler, plugin, mixer and project pages. STEPS → Push opens GEN8; MODE switches to VARY or BREAK. Wheel selects a row; DO IT executes it; BACK closes it. K1 controls amount, K2 genre and K3 repeatable seed.

The monochrome skin uses white foreground, black background, neutral panels, square markers, pixel numeric values and segmented gauges. Labels remain at least eleven pixels at 320×240. Selection and transport state use labels, outlines and icons as well as brightness.

See DESIGN.md and GEN8_BREAK.md for the current controls.
