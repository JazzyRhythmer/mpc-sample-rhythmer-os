# 프리셋·파라미터·패드 매칭 재검수

대상: Rhythmer OS 0.4.0-beta.3. Melodee 0.2.0 by Kerem Kiliç (Ellic Studio) 기반의 20개 플러그인 목록, 25개 소스 화면, Rhythmer Kit 36종 / 576개 패드를 검사한다. 카탈로그는 원본 2,616개 선택과 별도 승인된 Prophet/Elixir 43개 선택, 총 2,659개다.

## 확인하여 수정한 부분

| 영역 | 반영 |
|---|---|
| PRESETS / OUTPUT FILTER | Dexed·DRUM-X·Plaits·CS-1·MONO2K 출력 전체 필터를 추가했다. 원본 필터 누락 여부를 대조했으며 CS-1·MONO2K의 원래 필터 및 DRUM-X 노이즈·Plaits 모델별 제어는 유지한다. 첫 화면과 EDIT 값 연동, 중립 dry, 저장·복원·팩토리 재선택·panic을 검사한다. |
| Rhythmer Kit | 킷 내부 전체 필터를 추가했다. 패드 소스 필터와 분리하고 576개 목적지 패드에서 전체 범위·저장·복원·panic을 검사한다. |
| FMini-1 | 현재 Filter Release 값을 다시 써도 Release Follows Decay 연결을 해제하지 않는다. |
| Hortator / Acid | 0–127과 모델별 실제 정수 범위의 변환을 양방향 반올림으로 맞춘다. 현재 모델을 다시 써도 다른 편집값을 초기화하지 않는다. 원본 전 모델의 모든 정수 값 왕복을 검사한다. |
| 공통 편집 | 값이 같은 재입력은 작업 스레드에서 건너뛴다. 소리 상태와 수정 표시가 바뀌지 않는다. MODEL을 MOD로 잘못 정렬하던 규칙을 분리했다. |
| 킷 모델 전환 | Hortator 드럼↔Acid 전환 시 실제 소스 트리거 음정도 36↔60으로 갱신한다. 목적지 패드 번호는 유지한다. |
| DRUM-X | L0/L1 같은 내부 레인 번호와 A A 같은 중복 표현을 제거했다. Voice, Morph A/B, Macro, Source Output으로 기능을 구분한다. Clap Hands는 실제로 작동하는 Clap 소스에만 노출한다. |
| S1Vave / OberVave | 고정 원본의 값 표시 함수를 복원했다. 시간·주파수·부호 있는 오프셋·비율·템포 동기 값을 표시한다. S1은 LFO·필터·라이저·코드 보이스 명칭과 EDIT→ENV→LFO→FX→연주 순서를 정리했다. |
| TR-MPC | Distortion Type, Reverb Send, Delay Send 등으로 기능을 명시한다. 송신량은 %로 표시하며 Source FX와 호스트 트랙 효과를 구분한다. |
| Plaits | 원본 24개 모델별 파라미터 명칭을 반영했다. 내장 6-Op 96개 원본 프로그램을 PRESETS에서 직접 고른다. 중복 내부 프리셋 선택자와 무효한 FM Amount는 해당 세 모델의 EDIT에서 숨긴다. Model Decay와 Envelope Decay를 구분한다. 원본 quantizer의 1.02 배율을 반영하여 이름과 실제 프로그램이 일치한다. |

이전 수정인 User Sound/Kit 초기화 기준·편집값 보완 복원, 숫자로 시작하는 enum 해석, Aphex 오실레이터 표기도 재검사 대상이다. 기존 사용자 저장값은 유지한다. 새 프리셋을 임의로 만들거나 원본 DSP/뱅크를 재작성하지 않는다.

## 검사 방식

- 모든 프리셋을 실제로 로드해 파라미터 이름·중복·값·범위·단위를 읽는다. 같은 단어가 연속되는 표기도 검출한다.
- 대표 75개 소스 문맥에서는 모든 노브에 현재 값을 다시 쓰고, 소리 상태 전체와 수정 표시가 보존되는지 확인한다.
- 576개 패드 각각에서 실제 로컬 보이스 게인을 변경하고 음 출력 반응을 측정한다. 다른 15개 패드의 소리 상태가 바뀌지 않는지 비교하고 저장·복원한다. 번호 접두어만으로 매칭을 판정하지 않는다.
- 16개 모든 목적지 패드에서 드럼→Acid→드럼 전환, 소스 음정, 실제 발음을 확인한다.
- Plaits는 고정 원본의 실제 hysteresis quantizer를 컴파일해 32×32 전환을 검사한다. 모든 96개 프로그램 이름·실제 선택·발음을 함께 확인한다.
- 실제 제품 렌더러로 프리셋·EDIT·패드 소스·저장·빈 패드 화면을 검사한다. 최종 반복에서는 킷/패드 순방향·역방향·순열 조작을 사용한다.
- GEN·Acid·Break의 진입/뒤로가기·Seed·Undo/Redo·기록·복원과 고정 upstream의 16개 변경 항목을 별도로 검사한다.

최종 추가 3회 수락 결과는 VERIFICATION.md와 final-validation.lock.json에 기록한다. 수정 전이나 중간 실행의 통과 기록으로 현재 빌드를 승인하지 않는다.

## 원본 사운드 특성과 한계

작은 소리·긴 어택·DC·클리핑 후보는 원본 모듈 직접 출력과 대조했다. 결과와 해당 프리셋은 SOURCE_SOUND_CHARACTER_KO.md에 있다. 원본에 있는 레벨/어택/클리핑을 포트 결함으로 단정하거나 자동 보정하지 않는다.

모든 연속 파라미터 조합을 전수 조합한 것은 아니다. Motion MOD의 공통 호스트 대상과 엔진 내부 LFO는 별개다. 소프트웨어 검사와 실제 MPC에서의 청취·물리 패드/노브·CPU·USB·설치/복구 검증은 구분한다. 공개 배포는 보류한다.

beta.2에서 이 수정본으로 옮길 때는 전체 SD.zip이 필요하다. 앱 전용 UPDATE.zip에는 수정된 플러그인 바이너리와 카탈로그가 들어 있지 않다.

킷 패드 EDIT 제목은 `P11 / CS-1 / 사운드명`처럼 선택 패드·실제 엔진·소리를 표시합니다. 킷 전체 필터 행은 `킷 이름 / ALL PADS`를 표시합니다. 패드 소스를 교체해도 킷 프리셋 이름을 현재 소스 엔진으로 오해하지 않도록 구분합니다.
