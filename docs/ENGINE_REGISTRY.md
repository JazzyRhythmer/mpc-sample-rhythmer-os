# 0.2.0 engine inventory

0.2.0 contains **22 plugin-picker entries**. This is the applied release selection. Original names are retained.

Rhythmer Kit, Acid Engine, Break Engine, Sophie, Elixir, Aphex, FM-106, FMini-1, CS-1, OberVave, K-WASUB, Hera, Braids, Plaits, Hortator, MONO2K, Prophet, S1Vave, Dexed, Guru-600, Frodhes, Tenebrae

The native Sample Kit remains part of the original sampler and is separate from the plugin count. Seven source variants are available only inside Rhythmer Kit: DRUM-X, K-WASUB Drum mode, 6W6, 8W8, 9W9, CW-78 and TR-MPC. Sophie, Elixir and Hortator also remain individual instruments. Acid Engine uses the original Hortator ACID and Aphex acid-suitable programs.

There are 26 original engine cores, 27 source views including the Acid alias, 21 local port variants (20 repository names), and five unchanged upstream drum packages. Rhythmer Kit offers 36 factory kits, each filling pads 1–16. All non-kit instruments focus on one sound with chromatic/scale pads.

Excluded engines and their dedicated source folders, native build entries and package resources are removed. Reintroduction requires a fresh port and acceptance check. No previous-beta project conversion was added. Shared foundation sources and required predecessor notices are retained.

Device testing and public distribution are pending.
