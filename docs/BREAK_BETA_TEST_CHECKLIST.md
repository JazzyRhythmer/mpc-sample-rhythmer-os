# Break 실기기 베타 체크

소프트웨어 자동 검사와 별개로 MPC Sample에서 확인할 항목입니다. 완료 표시나 시간을 미리 채우지 않습니다.

| 목표 | 안내서만 보고 할 일 | 확인 결과 / 막힌 지점 / 소요 시간 |
|---|---|---|
| 첫 루프 | 빈 트랙에서 Break 선택, 1–4마디 지정, ORIGINAL 미리듣기, 로드, BRK PERF, PLAY | |
| 라이브 교체 전 비교 | 패턴 재생 중 브라우저 ORIGINAL / SYNC 비교, 다른 파일·드라이브로 이동, 취소 | |
| 첫 변형 | SOURCE에서 LOOP / Hold OFF, PLAY, Variation 올리기, ACTIVE 확인 | |
| Hold | Variation이 들릴 때 Hold ON/OFF 비교. CHOP에서는 적용 안 됨 확인 | |
| Stretch | ROLLS P3 유지 → GRAIN, STRETCH ACTIVE 확인, 값 조정 후 놓기 | |
| 이탈 | STRETCH를 누른 상태로 GEN / Back / 다른 트랙 진입, 명령이 남지 않는지 | |
| 소스 | 같은 길이 A 교체 시 패턴·B 유지, 다른 길이 확인 취소/적용, Undo/Redo | |
| 저장 | PROJECT SAVE 후 다른 프로젝트를 열고 원본 재열기. A/B와 패턴·설정 확인 | |
| 듣기 | 앞 무음/뒤 패딩 없는 원본으로 Straight → Genre → Random → Mutate 비교 | |
| 호환 | 일반 Sample Kit 미리듣기·악기·킷·MIDI 로드와 다른 트랙 연주가 유지되는지 | |

장치/설치 파일 해시, 프로젝트 BPM, 소스 파일·실제 마디 수, CHOP/LOOP, Hold, GEN Energy/Seed, 재현 버튼 순서를 함께 기록합니다. 다른 사람에게 테스트를 요청하거나 메시지를 보내지는 않았습니다.
