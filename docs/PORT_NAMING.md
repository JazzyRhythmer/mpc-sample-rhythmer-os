# Public port names

Original engine titles are preserved. Ports are collected in `JazzyRhythmer/mpc-sample-engine-ports`; the OS, installation package and host-side integration are in `JazzyRhythmer/mpc-sample-rhythmer-os`. The unofficial adaptation names below identify individual ports within that collection. The repository column records component slugs, not separate published GitHub repositories.
