# Break P0 / Rhythmer Kit 검증 결과

로컬 구현·ARM64 빌드·소프트웨어 검증 완료. 공개 배포, 설치 ZIP 교체, 실기기 설치/청취는 진행하지 않았습니다. 버전은 0.4.0-beta.3을 유지합니다.

## 변경한 흐름

| 동작 | 결과 |
|---|---|
| 처음 루프 로드 | 기존 노트·모션 등이 없는 패턴만 Straight 준비. 기존 음악은 보존. |
| A 교체 | 모든 패턴·길이·연주 설정과 패드 음색 설정 보존. 소스 위치에 의존하는 16개 트림/루프 위치는 재구성. |
| A의 마디 수 변경 | 기존 확인창 재사용. CANCEL/SHIFT+Push는 취소. LOAD A는 패턴 길이를 보존하고 B를 비움. Undo/Redo가 이전 A/B·마디 수·패턴을 함께 복원. |
| B 교체 | A의 선언 마디 수 사용. 패턴 생성 없이 SOURCE A/B로 복귀. |
| 패턴 생성 | 기존 GEN 메뉴에서 명시적으로 실행. K1 LENGTH는 기존 시퀀서 길이 조절이며, 브라우저 LOAD BARS와 별개. |
| 탐색·미리듣기 | Break에서만 비오디오 항목 숨김. 화면·커서·PREVIEW·로드가 동일한 목록을 사용. 일반 Sample Kit의 킷/악기/MIDI 로드 유지. |
| 연주 화면 | 기존 B1 GEN, B2 LOAD A/LOAD B, B3 RETURN 유지. SOURCE A/B에 A 로드 경로 안내. Note Repeat 우선순위와 단축키 유지. |

기존 비동기 작업의 트랙 소유권, 로딩 취소, 디코드 오류 후 재선택, Freeze 보호 및 다른 트랙/화면으로 이동한 뒤 화면을 빼앗지 않는 규칙을 유지했습니다. 새 로드 확인창은 기존 Ask 모달을 재사용합니다.

## Rhythmer Kit

승인된 v6 기하학/속도/감쇠 코드는 이미 들어 있었습니다. `Kit / Pad N: Sound *` 표시명이 패드마다 바뀌면 전체 모션이 초기화되는 연결 문제를 수정했습니다. 모션 상태를 구분할 때만 패드 접미사와 편집 표시를 제외합니다. 화면의 프리셋/패드 이름은 그대로이며, 실제 킷이 달라지면 모션도 새로 시작합니다. 다른 엔진과 DSP는 바꾸지 않았습니다.

## 통과한 검사

- 최종 ARM64 빌드 및 기존 GEN/Acid/Break 회귀 검사.
- 트랙 워크플로우 290 assertions: 128패턴 유지, 실제 플러그인, Undo/Redo, 탐색 소유권, EMPTY MIX, 확인창 Back.
- 새 A/B 교체·길이 변경 확인/취소(SHIFT+Push 포함)·저장 복원·6개 소스 진입 경로·브라우저 목록 검사.
- 실제 UI 렌더 11화면: 텍스트 넘침 0. 파일 목록은 문서용 예시이며 실기기 촬영이 아닙니다.
- 같은 입력 96프레임 × 1×/2×: 고정 킷명과 변경되는 패드명 간 192개 이미지 전부 일치. 패드명 변경으로 발생하던 모션 리셋 방지.
- 고정 upstream에 통합 패치 재적용: 137파일 모두 현재 런타임과 일치.
- 매뉴얼/그루브 가이드: 중복 ID 없음, 소스/패턴 길이·A/B·Back 경로 일치, 변경 캡처 해시 일치. UI 캡처와 소프트웨어 재현은 실기기 조작·청취 검증을 대신하지 않습니다.
