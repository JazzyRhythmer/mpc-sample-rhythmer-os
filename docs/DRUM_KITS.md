# Rhythmer Kit banks

Rhythmer Kit is first in the plugin picker. PRESETS changes the whole kit; Pad / Engine / Sound changes only the selected pad. All 36 kit presets fill pads 1-16. Individual engines remain single sounds with chromatic/scale pads.

| Source | Whole-kit selections | Sound source |
|---|---:|---|
| DRUM-X | 9 | Original nine factory kits |
| Elixir | 5 | Original Initkit plus Dry Circuit, Warm Machine, Bright Logic and Soft Pulse authored for Rhythmer |
| Hortator | 12 | Six retained arrangements plus six MD arrangements of original factory sounds |
| K-WASUB Drums | 4 | Original 808, 909, Dub Techno and Acoustic |
| Sophie | 1 | Original default pad voices |
| 6W6, 8W8, 9W9, CW-78, TR-MPC | 5 | Original MPC modules |

[Hortator list and all pad assignments](HORTATOR_KITS_KO.md) includes all 36 kit names. The six added MD kits use Hortator on all 16 pads. Existing smaller kit layouts retain complementary original Sophie percussion. These are pad arrangements, not newly synthesized factory patches.

Elixir offers the original GPL Initkit and four independently authored seven-voice kits, with all 35 voices available individually. The separate Erica/Hrtl factory/DLC banks are excluded from this distribution. See [Rhythmer preset credits](RHYTHMER_PRESETS.md) and [the original preset audit](ORIGINAL_PRESET_AUDIT_KO.md).

GEN reuses the FM-1 four-track logic: the first destination is Rhythmer Kit; the following three are melodic instruments. Destination groups are 1-4, 5-8, 9-12 and 13-16. MIDI-only generation preserves the selected sound. See GEN_WORKFLOW.md.

Five VCSL CC0 recordings remain available in the existing sampler with their attribution. The Hortator synthesis-only port explicitly excludes the four original sample-model presets that depend on absent sample assets. The native MPC Sample Kit loading workflow is retained.
