# Rhythmer OS quickstart

Load a sample kit or choose one of the 20 instruments from PLUG-INS. Rhythmer Kit has 36 complete kits; other instruments play one sound chromatically or in scale.

Press SEQ for PATTERNS. Hold SHIFT and press B3 GEN. Select GENERATE SONG to assign a kit and three instruments to tracks 1–4, 5–8, 9–12 or 13–16. GEN SETUP changes the target or chooses MIDI-only tracks. GENERATE TRACK keeps the selected instrument. Turn the seed to reproduce a pattern. BACK returns from Acid/Break to GEN, then PATTERNS.

Stage B1 shows PRESETS with the engine artwork and its real filter or representative sound controls; B1 again opens EDIT. B2 opens PERFORM (DJ FILTER / ECHO / SPACE), then ARP / CHORD. Rhythmer Kit has its own whole-kit filter, saved with its presets; KIT labels mean all pads and P11 labels mean pad 11. Sample Kit / Break land on SOUND with their existing whole-track filter, followed by TRIM. The encoder or −/+ moves native parameter rows; K1–K3 edit the highlighted controls. In Edit, B3 opens SAVE (Rhythmer Kit cycles SOURCE / SAVE / EDIT). SHIFT+B3 toggles plug-in TRANSPORT. Double-tap STOP cuts all audio.

New plug-ins go in Rhythmer/Plugins on the card. Existing top-level Plugins remain readable. Use the device page or Files over USB at http://rhythmer.local. Firmware updates must be signed Rhythmer OS releases.

Based on Melodee by Kerem Kiliç (Ellic Studio). Developed by jazzy rhythmer.

## Start from an empty track or pad

Press SAMPLE, then use SOUND or TRIM. On a completely empty Sample Kit, Push the encoder to open TRACK TYPE: PLUG-IN opens the instrument browser; SAMPLE KIT opens the first-sample browser. On a selected empty pad with samples elsewhere in the kit, Push opens SAMPLES for that pad. Select a file and Push to load it. Hitting another pad in the browser changes the destination, so check the selected pad before loading. All 128 pads and secondary layers count as existing content.

The face shows PUSH: TRACK TYPE or PUSH: LOAD SAMPLE. SHIFT + Push closes the browser and returns to its caller. B1 goes up a folder, or returns to the caller at the browser root. SHIFT + Minus undoes a sample assignment. A never-assigned or intentional EMPTY track retains the native type carousel. Loaded pads, other edit pages and Break loop loading retain their existing clicks. Use TRACKS → B1 TRACK SETUP for other instrument/type changes and track deletion.

## Preset browsing

Turn the encoder or use Minus/Plus: the last entry wraps to the first and the first wraps back to the last in the current preset list, including User Sound/User Kit. Absolute pot selection and the existing LOAD/debounced preview timing stay unchanged. Acid Engine adds the original Aphex presets Acid Squelch, Lead Scream, Whistle Lead, Resonant Spike, Acid Seq, Reso Bass, Filter Cry and Techno Pulse alongside its four Hortator Acid presets. Each uses its original DSP and matching filter/edit controls.
